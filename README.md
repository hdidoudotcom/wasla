# Wasla

Automatic Instagram replies (private messages and comments) for several businesses, with a shared inbox for the team.

- Static app (`/app/`) on Netlify, Supabase (Postgres + Auth + one Edge Function `instagram`).
- Official Instagram API with Instagram Login: no Facebook Page or Business Suite needed; the Instagram account must be professional (Business or Creator).

See PROJECT_HISTORY.md section 3 for the setup steps.
